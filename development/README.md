# Soccer Training App - Development Tools

This folder contains development scripts, fixes, and experimental code.

## Folder Structure

- **scripts/** - Development and deployment scripts
- **fixes/** - Bug fix scripts and patches
- **experiments/** - Experimental code and proof-of-concepts

## Development Scripts
- `apply_video_fixes.py` - Video processing bug fixes
- `add_drill_progress_api.py` - Script to add drill progress API endpoints
- `manual_drill_progress_endpoint.py` - Manual drill progress endpoint implementation
- `simple_drill_progress_endpoint.py` - Simplified API endpoint version

These scripts were used during development to add features and fix issues on the backend server.
