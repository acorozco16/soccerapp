# Beep Sound File

This is a placeholder for the beep.mp3 sound file that should be added here.

For now, you can:
1. Download a short beep sound (0.5-1 second) from freesound.org or similar
2. Convert it to MP3 format
3. Name it `beep.mp3` and place it in this assets folder
4. Remove this placeholder file

The sound will be used for:
- Countdown timer beeps (3, 2, 1)
- Final 3 seconds of recording/practice timer
